# ThreadSanitizer suppressions for the thread lane, which
# scripts/sigil/sanitize.py points the runtime at.
#
# An entry belongs here only for a dependency this lane is structurally
# unable to judge, and only with the reason written down. A race in this
# repository's own code is never suppressed — it is fixed.

# workaround: concurrentqueue publishes each constructed slot through a
# release tail index and acquires that index before reading the slot. The
# dependency identifies its lock-free operations as a TSan false-positive
# boundary; suppressing its implementation leaves the scheduler's own slot,
# frame and lifetime synchronization instrumented.
