# Archive

**Nothing in this directory is current. Do not build from it, quote it,
or cite it.**

These are process records — a closed work ledger and an audit of a change
that shipped. They are kept for the reasoning they contain, not as a
description of the engine.

Both have drifted from the code in specific ways: they cite line numbers
that have moved, describe fixes as pending that are applied, and quote
measurements taken on a CPU-raster path that were never meant to
generalize. The audit's "prepared patch — do not apply" is in fact
applied, byte for byte.

The current description of the library is `../README.md`. Where anything
here disagrees with that document or with the headers, it is wrong.
