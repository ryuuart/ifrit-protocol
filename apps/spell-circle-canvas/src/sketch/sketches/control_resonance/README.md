# Resonance Bureau

An original, animated evidence folio inspired by *Control*. A dense institutional
document sits beside a suspended inverted concrete structure. Red light, carrier
interference and a breathing warning interrupt the paper's restrained hierarchy.
The case, personnel and report text are invented for the study.

Selected phrases carry attached redaction boxes, so censorship follows the
shaped text instead of fixed page coordinates. The pyramid is retained native
pen geometry, with concrete courses and a projected floor. A file-backed
material draws travelling interference bands for the moving red pressure, and a
small uncached pen program draws three live instrument traces. The structure
and warning use native motion bindings over an 8-second phase.

The canvas is 1440 × 960. Its catalogue still is at 3.4 seconds.

Reference direction: bureaucratic typography, red contamination, massive
geometric construction and stepped architectural detail. The folio, diagram and
prose are original, rather than a transcription of an in-game collectible.
