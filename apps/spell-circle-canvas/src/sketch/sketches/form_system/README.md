# Form / System

An original kinetic typographic score: FORM, FOLD, FLOW and FLUX each occupy
one row in a sixteen-cell modular grid. Expansion, rotation, compression and
countermovement run as offset phases across the letters. Cobalt and acid
yellow make positive and negative letterforms alternate across the field.

The grid uses fractional native layout tracks. Its parent participates in
layout; a positioned subtree cannot run an arranging operator. Each cell
centres its own letter, whose paint transform moves without changing the
cell's measure. The header and colophon sit on the same four-column grid.

Reference: [Josef Müller-Brockmann, designer foundation](https://syjmb.foundation/en/josef-mueller-brockmann/).
The composition and motion are original, rather than a historical facsimile.
