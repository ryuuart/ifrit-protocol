# Cosmic monochord

A generated engraving after Robert Fludd's *Monochordum mundanum* in
*Utriusque cosmi historia*. The reference's central soundboard, figured sun,
planetary signs, stellar belt, elemental labels, tuning hand, and nested
musical-interval brackets supply the composition. The cosmos is presented
as a historical system of correspondences, rather than a physical model.

The source engraving is visually inspected through the
[public-domain plate](https://publicdomainreview.org/essay/robert-fludd-and-his-images-of-the-divine/).
[Cornell's object record](https://digital.library.cornell.edu/catalog/ss%3A18168108)
identifies the diagram and its publication. The
[Linda Hall Library account](https://www.lindahall.org/about/news/scientist-of-the-day/robert-fludd/)
describes the planetary tones and interval brackets and explains the
distinction between Fludd's correspondences and Kepler's measured harmonies.
The reference image is not bundled or used as a rendered layer.

This is a composed interpretation, not a facsimile or diplomatic
transcription. Enlarged lettering, rubric annotations, the marginal compass,
English glosses and the small string vibration are authored additions.
The hand, cloud, soundboard, stars and solar face are constructed native
vector drawings. Labels preserve the general interval vocabulary; fret
positions are reconstructed visually and do not implement a tuning solver.

The engraving is retained as vector commands, including the shaped curved
inscriptions. Static paper fibres, shallow gutter shadow and sparse foxing
are generated by a local material program. A separate narrow string material
combines a decaying fundamental and third partial, with fixed ends. The
string changes while the rest of the plate stays fixed. No animation requires
re-description of the page.

Open `fludd_monochord.cpp` in Sketchbook, or select it under **Study ·
Manuscript**. The canvas is 1340 × 1720 and the declared still is at 4.8
seconds. A new excitation begins every six seconds.

From `apps/spell-circle-canvas`:

```sh
build/bin/Release/Sketchbook.app/Contents/MacOS/Sketchbook \
  src/sketch/sketches/fludd_monochord/fludd_monochord.cpp \
--frame /tmp/fludd-monochord.png --at 4.8
```

The current source compiled in the native file host and was captured at
0.32 and 4.8 seconds. Both plates were visually inspected. A pixel comparison
confined all changes to x651–652 / y374–1441, inside the string column;
the engraving, paper and shaped inscriptions stayed identical. File captures
use the host's raster canvas. The window lane supplies separate Graphite
verification rather than changing the backend of this exact-time still.

The bounded file-window run presented only this study, reported
`renderer: Graphite GPU` and completed without shader errors. Repeat it
with the same file argument and `--window-bench 2.5 --gpu`, omitting the
`--frame` argument and using a separate state directory.

The authoring pressure points are curve-relative label placement,
consistency between curve geometry and text placement, font coverage for
planetary signs, and keeping dense fine line work intact at capture scale.
The findings queue holds verified library problems; reference-specific
construction remains in this sketch.
