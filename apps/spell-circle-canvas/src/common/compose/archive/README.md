# Archive

**Nothing in this directory is current. Do not build from it, quote it,
or cite it.**

These documents are kept because they record how the library was argued
into its present shape, and that reasoning is occasionally worth reading.
They are not a description of what the code does now. Several of them
state things the code contradicts — layout phases that were re-counted,
cache keys that gained or lost a component, cross-references to sections
that no longer hold what they point at, and figures that were superseded
by later measurement.

The current description of the library is `../README.md`. Where anything
here disagrees with that document or with the headers, it is wrong.

If you are looking for measured numbers, run the benchmarks — the
`compose_bench` target and the plate ledger own them. The figures written
down here were true on one machine on one day and nothing has re-checked
them since.
