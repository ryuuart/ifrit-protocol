# Guides

Task-shaped pages: one thing you want to do, start to finish, in both
languages. They are the way in. The
[reference](../../src/common/compose/reference/VALUES.md) is what you
read afterwards, when a signature asks for a value and you want to know
what makes one.

Every guide runs against a **sketch** — one file that declares a scene,
which Sketchbook opens and hot-swaps on every save. Nothing here needs
the product, a window server or a network.

## Start here

1. **[Put a coloured rounded box on the page](a-coloured-rounded-box.md)**
   — a canvas, a box, a fill and a corner radius, and the two ways to
   run it. Fifteen lines.
2. **[Animate a fill](animate-a-fill.md)** — make the colour move, three
   ways, and the one thing you must declare so a cache does not freeze
   it.
3. **[Write a sketch in Python](a-sketch-in-python.md)** — the same API
   from the other language: install, render a still, open it live.
