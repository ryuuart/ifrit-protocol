# Light table

A 1440 × 1080 Compose material inspection desk: satin aluminium, raised gold
letters, an enamel brush deposit, copper pressure bands and tilted normal
coupons. The primary light has no ambient or environment share. Frontal light
shows broad interior normals; raking light picks out ridges and lettering. The
letters use flatter brushed normals so their faces stay legible. Every surface
is a flat material response, with no cast shadows or depth.

## Controls

Drag Brightness, Bearing or Elevation, or pick a Key Color chip. KEY, POINT
and SPOT choose the source kind. Point and Spot enable X, Y, Height and Range;
Spot also enables the inner and outer cone. Dragging on the specimen moves a
positioned source. Every edit enters MANUAL. HOLD freezes the current values;
PREVIOUS and NEXT hold a state's midpoint; AUTO restores the timed study.
Bearing runs counter-clockwise from the right, and an elevation of 90 degrees is
frontal. Height and Range are in the main scene's logical pixels. Brightness
runs from 0 to 0.45 and bounds the summed primary strength, which Mixed shares
between key and fill. Colours stay within the display range.

## States

The 32-second loop has eight four-second states:

| Seconds | State | What changes |
|---|---|---|
| 0–4 | Front | Curved plate interiors and four opposite normal slopes. |
| 4–8 | Rake | Bristles, raised glyph shoulders and pressure bands. |
| 8–12 | Bearing | The source turns while the specimen stays still. |
| 12–16 | Live RGB | One source changes from red through green to blue. |
| 16–20 | Black | Primary materials go dark; the interface and the nested cool scene remain. |
| 20–24 | Point | Local placement with range falloff. |
| 24–28 | Spot | A soft cone until 26 seconds, then a hard cutoff with equal inner and outer angles. |
| 28–32 | Mixed | A warm directional key and a cool positioned fill. |

Below the specimen, paired cards compare flat ink with raised letters, a source
declared first with one declared last, and a cached picture with live content.
Each card of a pair has its own scene with the same local source placement,
range and cones, so Point and Spot read alike across the pair. A fourth card
holds a cool scene nested inside the primary one, lit only by its own fixed
source, and stays the same through every state.
